# The Fabric of a Day

Glucose Textile Studio — a browser-based creative authoring prototype for transforming 24 hours of personal glucose data into machine-knitted textile designs.

## Getting started

Open `index.html` locally, or use the GitHub Pages site once enabled. Try `sample-glucose-24h.csv` (synthetic data), or import your own timestamped glucose CSV. Choose a data feature, mapping, yarn colors, pattern intensity, custom motif and personal event markers. Preview the scarf and export a two-color production PNG.

## Fabrication

Import the production bitmap into Customist Studio, configure the appropriate two-color jacquard structure, yarns, gauge, cast-on and bind-off, then generate machine instructions for Kniterate. The prototype does not generate K-code directly. Physical knitting and Customist import have not yet been verified; test a swatch first.

## Privacy

The application processes data locally in the browser. Do not commit real participant glucose data or exported personal projects to this public repository. This is an artistic research prototype, not a medical device or clinical decision tool.
